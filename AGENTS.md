Always run test.sh + lint-determinism.sh + `luajit -bl` on changed Lua before committing. Commit and push after changes.

## Rules
- Game rules go in `model/` with NO Factorio globals (`game/storage/script/defines/surface`); in-game code is a thin adapter. Test models offline; engine behaviour only via in-game spikes. Mocks encode beliefs, not evidence.
- Factorio 2.0 Lua API: Reference https://lua-api.factorio.com/latest/ for exact classes, parameters, and signatures.
- Lua 5.2: no `|`, `&`, `//`, `goto` ok. No `math.random`/`os`/`io` outside spikes (use `game.create_random_generator`). Never store functions in `storage`. Register events via `scripts.events` at load time only. Schema changes need a `store.lua` migration.
- Do not edit vanilla prototypes (opt-in design pillar). Don't scan entities per tick; use registries + `scheduler`.
- Spike/decision outcomes: record on the GitHub issue (comment + close), update docs/design doc if the design changes. Track progress via `gh issue` and project milestones.

## Decisions made
Territory = chunk-granular 32x32 (#15). Space Age required (#12). Watchtower = 1-chunk ring, must be built on claimed land (#56). Farming = player-placed plots + tile fertility table (#44 first pass). Crates are plain containers (belts/inserters still work), driven by our own registry (#33). Construction = pay the ghost's `items_to_place_this` from colony stock, carry it, `revive`; repairs = one repair pack per 200 health (#37). Job locks are per-house, ore priorities are per-hut. Spoilage is cleared by colonists (free on a delivery trip, plus a lowest-priority haul band) into a Compost Bin that batches 10 spoilage -> 1 fertilizer (#78). Hunting is real engine combat against docile game: boars live on their own `colony-wildlife` force (cease-fire both ways, so no aggro and no turret fire), hunters get `defines.command.attack`, and the colonist prototype carries a ranged hitscan attack with `vision_distance` 1 so nobody picks a fight unasked; a kill is credited to the hut from `on_entity_died`'s `ev.cause` (#79). Blueprint/copy-paste persistence rides on `BlueprintEntity.tags` (one namespaced key, dense row lists, `model/tags.lua`) because `storage` is invisible to a blueprint and `LuaEntity.tags` is ghost-only (#36). Open decisions: #18-#22 (housing, science, disease, tourism, perf budget).

Hall -> territory (watchtowers extend it); tents/cabins hold real inventories and per-house occupant rosters (locks live on the house, not the hall); colonists loop haul/forage/chop/mine/farm/hunt (`work.lua`, `model/work_plan.lua`); harvest yield lands in the worker's hut and haulers clear it inward; axes/pickaxes/hoes/rifles wear and are delivered from the Hall; hunters shoot roaming boars for raw meat; opt-in machines are supplied and emptied via the marker tool; supply crates feed the colony stock, demand crates are filled to filters, and warehouses act as bulk stock; spoilage is cleared out of houses and stock into a compost bin that batches it into fertilizer; builders revive ghosts inside territory and repair colony buildings with repair packs; opt-in flag, supply rows and crate filters survive blueprints, copy-paste and clones; desirability reads real food/housing/leisure plus sampled tree/water/paving cover and pollution at the hall, and colonists leave when it collapses.
