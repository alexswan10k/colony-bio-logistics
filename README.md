# Bio-Logistics Colonies (Factorio 2.0 + Space Age)
Colony-simulation mod. See [the design document](factorio_colony_mod_design_document.md).
Status: **pre-alpha / feasibility spikes** (see GitHub milestone M0).

## Dev
- `scripts/link-dev.sh` symlinks `mod/` into your Factorio mods folder.
- `scripts/benchmark.sh <save> [ticks]` runs a headless benchmark (`FACTORIO_BIN` required).
- Spike #1 commands (in game): `/spike_units N`, `/spike_report`, `/spike_clear`.
