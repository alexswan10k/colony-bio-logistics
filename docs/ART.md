# Art plan (issue #13)
Policy: **no feature blocks on art.** Every entity ships with a placeholder (tinted vanilla sprite + generated icon) until the milestone's playtest passes.
Minimum assets per milestone:
- M1: colonist (walk/idle/work), town hall, tent/shack, labour huts (forager/woodcutter/miner/farm), crates x3, compost bin, hunting lodge, wild boar, fishing dock, selection tool/shortcut icons, badge icon, ~16 item icons (incl. basket/axe/pickaxe/hoe/rifle/rod, meat/fish/fertilizer).
- M2: 3 science packs, archive/university, homestead, apartment, farm, kitchen, smokehouse, salt pan, clinic, taverns, passenger coach + platform, canteen, resort.
- M3: armory, watchtower, patrol post, motor pool, whistle tool.
- M4: habitat dome, orbital dome, hydroponics, nursery, airlock, pod item, suits, gear icons.
Decision needed from owner: placeholder-only for MVP vs commissioned/AI-generated sprites.
